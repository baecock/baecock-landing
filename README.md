# 배콕 (Baecock) 소개 페이지

배드민턴 클럽 운영 앱 **배콕**의 사전 홍보용 랜딩 웹사이트입니다.

밴드, 엑셀, 카카오톡, 종이로 흩어진 배드민턴 동호회 운영을 하나의 앱으로 모으는 것을 목표로 하며, 이 사이트는 방문자가 로그인 없이 매칭 기능을 바로 체험해보고 앱 설치까지 자연스럽게 이어지도록 안내합니다.

## 기술 스택

빌드 도구, 백엔드, DB, 로그인 연동이 전혀 없는 **완전 정적 사이트**입니다.

- HTML / CSS / Vanilla JavaScript
- 별도의 패키지 매니저나 빌드 과정 없이 브라우저에서 바로 실행

## 페이지 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 소개 페이지 (Hero, 서비스 소개) |
| `match.html` | 매칭 체험 페이지 (참가자 입력 → 랜덤 매칭 결과) |
| `features.html` | 앱 기능 소개 페이지 |
| `terms.html` | 이용약관 |
| `privacy.html` | 개인정보처리방침 |

## 폴더 구조

```
.
├── index.html
├── match.html
├── features.html
├── terms.html
├── privacy.html
├── css/
│   ├── tokens.css   # 색상/간격/반경 등 디자인 토큰
│   └── style.css
└── js/
    └── match.js     # 매칭 체험 로직 (서버 미저장, 로컬에서만 동작)
```

## 실행 방법

빌드 과정이 없으므로 `index.html`을 브라우저에서 바로 열거나, 로컬 서버로 띄워서 확인할 수 있습니다.

```bash
npx serve .
```

## 주요 원칙

- 매칭 체험은 서버에 데이터를 저장하지 않습니다 (로그인/서버 저장 기능 없음)
- 커뮤니티 탭, 블로그 등은 스코프 밖입니다
